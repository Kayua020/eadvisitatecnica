# Tecnologia e Inovação

Esta página foi criada para a atividade de Programação Web do curso de Análise e Desenvolvimento de Sistemas. O tema escolhido foi Tecnologia e Inovação.

## Arquivos do projeto

- `index.html`: contém a estrutura e o conteúdo da página.
- `style.css`: define as cores, os tamanhos dos textos, o layout, a imagem, a lista, o botão e outros detalhes visuais.
- `script.js`: adiciona a interação que acontece quando o botão é clicado.

## Respostas às perguntas da atividade

### 1. Qual é a função do HTML na página desenvolvida?

O HTML organiza o conteúdo da página. Nele foram criados os títulos, os parágrafos, a imagem, a lista de possibilidades tecnológicas, o botão e o rodapé.

### 2. Onde você utilizou CSS e quais alterações ele realizou?

O CSS foi utilizado no arquivo `style.css`. Ele mudou a cor de fundo da página, as cores e os tamanhos dos textos, a aparência do botão e a organização dos elementos. Também adicionou espaçamento, bordas arredondadas, sombra nas seções e ajustes para telas menores.

### 3. Onde você utilizou JavaScript e o que acontece quando ele é executado?

O JavaScript foi utilizado no arquivo `script.js`. Quando o usuário clica no botão “Mostrar mensagem”, o texto do parágrafo é alterado e sua cor de fundo muda para destacar a mensagem.

### 4. Qual é a principal diferença entre CSS e JavaScript?

O CSS é utilizado para definir a aparência visual da página, como cores, tamanhos, espaçamentos e posicionamento. O JavaScript é utilizado para adicionar comportamentos e interatividade, como alterar um texto depois que o usuário clica em um botão.
